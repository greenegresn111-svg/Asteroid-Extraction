# Asteroid Extraction

## Project Option
Simple Browser Game

## Project Description
Asteroid Extraction is an incremental clicker game where the player mines an asteroid in space to collect resources. The user starts by clicking an asteroid on the screen which gives the resource. There is a store menu where the player can upgrade their drill, buy automated mining drills (clicks for the player), and advance technologies which multiplies the resource gain from other sources.

## Theme Interpretation
This project utilizes the idea that the play is in space harvesting resources from an asteroid, to build a Dyson Swarm.

## Intended User or Player
This project is designed for gamers of all ages who like to play incremental clicker games.

## User or Player Goal
Try to collect enough resources to build a Dyson Swarm.

## Main Features
Clickable asteroid
Store upgrade interface
Reset button
Dyson Swarm completion meter

## JavaScript Features
I used JS to handle the math and clickable events, using the HTML code 'onclick="function-name()"'. I also used JS to handle the simulation of time passing using 'setInterval(() => {}, 1000);'. I also used JS to change different aspects of the html interface, ranging from, style changes to adding classes which determine if a information is hidden.

## Responsive Design
The project automatically adjusts the position of my elements and aligns them according to the screens size. I also made it so when the screens width drops below 1024px it flips the display of my game, so the main game screen sits on top of the store menu instead of to the left of it.

## User Testing
I had four people test my game by completing four goals, which aligned with the progression line of my game. The main confusion point was the lack of indicators for the users' upgrades. They each said every interaction in the game worked flawlessly. The interaction which needs improvement is the clicking of the asteroid, I need to add an indicator which displays how many resources you gather with each click. Each tester recommended that I add a counter which displays how many upgrades have been purchased. As well as fixing the display and layout issues that came with resizing the screen/display.
